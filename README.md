# Digital Portfolio

This is a static portfolio website built with HTML, CSS, and JavaScript.

## Deploy to GitHub Pages

1. Create a GitHub repository for this project.
2. Add a remote and push from this folder:

```bash
git remote add origin https://github.com/<your-username>/<your-repo>.git
git branch -M main
git add .
git commit -m "Initial portfolio site"
git push -u origin main
```

3. Enable GitHub Pages in repository settings or let the workflow deploy automatically to the `gh-pages` branch.

4. Optionally, configure the Pages source to the `gh-pages` branch.
